# 江西民俗节庆地图

基于《全国民俗节庆总表（合并整理版）》中的江西条目制作的交互地图。

- 收录178条记录，覆盖11个地市、92个县级地区。
- 支持3D立体与平面切换、拖动旋转、缩放和还原视角。
- 支持地市选择、节令筛选、关键词搜索，以及活动详情和原表行号查看。
- 可导出地图图片，也可下载配套的 [3D静态图片](./jiangxi-map-3d.png)。

## 使用

直接打开 `index.html` 即可离线浏览。页面包含全部样式、地图边界和活动数据，不需要安装依赖或构建。

## 数据说明

主表“省份＝江西”共178条：177条归属地市，1条“立冬补冬吃麻糍”为全省习俗，未重复计入各市。名称相近的活动、子项目及文旅节会按原表分别保留。

举办时间保留原表的农历、公历、节令及待核实表述，包含往届日期和隔年举办记录，不代表2026年活动安排。

各市采用统一立体高度，仅用于立体展示，不表示海拔或活动数量。底图表示地市行政区域，不是具体活动场地坐标。

边界来源：[阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)；[江西地市边界数据](https://geo.datav.aliyun.com/areas_v3/bound/360000_full.json)。
